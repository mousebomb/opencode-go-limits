# 20260910 修复 OpenCode Go 表格解析失效 + 隐藏无法估算模型

## 原始需求

OpenCode Go 用量工具的表格"又坏了"，要求查因修复。查因后补充要求：仔细验证等价性，并隐藏无法估算的 MiniMax M2.5。

## 查因结论

数据源 `anomalyco/opencode` dev 分支的 `go.mdx` 被官方改版，`index.html` 的解析锚点全部失配：

1. 价格+额度表锚点 `预估值还基于以下每 1M tokens 的价格...` → 新版改为 `Token 价格按每 1M tokens 列示。`
2. 官方对照表锚点 `下表提供了基于典型 Go 使用模式的...` → 新版改为 `下表根据典型的 Go 使用模式...`
3. patterns 的结束锚点 `预估值还基于以下每 1M tokens 的价格` 被删除（导致 body 延伸到文档末尾）
4. 额度字段从 `$60` 变为 markdown 加粗 `**$60**`，`money()` 解析成 NaN → 估算月请求全 NaN

## 实现小结

- `section()` 重构为支持多备选锚点（`indexOfAny` 辅助），命中任一即可，官方再改版也不易全挂；旧锚点保留，向后兼容旧文档格式。
- `parsePatterns` 结束锚点增加 `你可以在 **` 备选。
- `money()` 正则改为 `[$*\s]`，兼容 markdown 加粗 `**$60**`。
- 隐藏无请求模式的模型：`render()` 只渲染 `monthly != null` 的档位（不再在底部拼 N/A 行），对数刻度改用过滤后的 `ordered`；`renderDetailTable` 同样过滤。官方日后补了该模型请求模式会自动重新出现。
- 未改动任何渲染/交互/i18n/缓存逻辑，变更面极小（26 增 9 删 → 修复，5 增 6 删 → 隐藏）。

## 等价性验证

- 构造旧格式 mock mdx：新旧解析逻辑输出逐字节一致（prices/patterns/official 全同），`money()` 对 `$60`/`$0.15`/`-` 兼容，唯一差异是 `**$60**` 旧代码 NaN、新代码 60（正是被修复的 bug）。
- 新格式 36 档位全部解析，35 个与官方对照值偏差 ≤0.5%，1 个 N/A（官方本无请求模式的 MiniMax M2.5，隐藏处理）。
- 锚点唯一性检查通过；浏览器实测渲染/语言切换/缓存写入均正常。
- 多档位模型（DeepSeek V4 Flash Peak/Off-Peak 等）标 ▲ 属正常：官方对照表只给模型汇总值，估算按档拆分，偏差是官方口径所致，非回归。

## 使用方式

同前：双击 `index.html` 或线上 `mousebomb.org/opencode-go-limits/`。
